# 🏑 Hockey World Cup 2026 Prediction

A Python-based **Simulation model** to predict the outcome of the **2026 Men's Hockey World Cup**.

The project simulates the complete tournament pathway, including the **group stage, second round, semi-finals, and final**, and estimates the championship probability of each participating team.

---

## 📌 Project Overview

This project uses team ratings and probabilistic match simulations to model possible outcomes of the 2026 Men's Hockey World Cup.

The simulation includes:

* 🏑 Team strength based on FIH rankings
* 📊 Win probability calculation using team ratings
* ⚽ Expected goals estimation
* 🎲 Poisson-based match simulation
* 🏆 Group-stage qualification
* 🔄 Second-round simulation with carried-forward results
* ⚔️ Semi-final simulation
* 🥇 Final simulation
* 🎯 Penalty shootout simulation for tied knockout matches
* 🔁 **100,000 complete tournament simulations**
* 📈 Championship probability estimation
* 📋 Most likely group rankings
* 💾 Export of prediction results to CSV

The team ratings used in the notebook are sourced from the **FIH outdoor hockey rankings**.

---

## 🧠 Methodology

### 1. Team Ratings

Each team is assigned a rating, which is used to estimate the probability of one team defeating another.

The probability is calculated using an Elo-style formulation:

```text
P(team1 wins) = 1 / (1 + 10^((R2 - R1)/400))
```

The notebook implements this through the `win_probability()` function.

### 2. Expected Goals

Expected goals are estimated from the calculated win probability:

```text
xG₁ = 1.5 + 3P
xG₂ = 1.5 + 3(1-P)
```

These values are then used as the parameters of Poisson distributions for generating simulated match scores.

### 3. Tournament Simulation

Each complete tournament simulation follows the structure implemented in the notebook:

```text
Group Stage
     ↓
Second Round
     ↓
Semi-Finals
     ↓
Final
     ↓
Champion
```

The tournament simulation is repeated **100,000 times** to obtain a distribution of possible outcomes.

## ⚠️ Disclaimer

This project is a **simulation-based prediction**, not an official forecast.

The results depend on:

* Team ratings used in the model
* Probability formulation
* Expected-goal assumptions
* Random Poisson sampling
* Tournament structure implemented in the notebook
* Number of simulations

Therefore, the predicted championship probabilities should be interpreted as **model-generated estimates rather than guaranteed outcomes**.
